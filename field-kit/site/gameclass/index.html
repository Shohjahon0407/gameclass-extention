Nima qiladi

Faqat o'qiydi

Alohida «faqat o'qish» login yaratiladi. GameClass'dagi seans, pul va sozlamalarga tegmaydi — buni SQL Server'ning o'zi kafolatlaydi.

Zal xaritasi va kassa

Klub xaritasini chizasiz — mijozlar ham uni ko'radi. Kassir uchun GameClass tariflari bo'yicha narx hisoblagich bor.

O'zi ishlaydi

Windows xizmati sifatida kompyuter yonishi bilan ishga tushadi. Sozlash taxminan 5 daqiqa, texnik shart emas.

Qanday o'rnatiladi

  1. Yuklab oling va ochingGameClass Server o'rnatilgan kompyuterda «ManajoyGameClass-Setup» faylini oching.
  2. Shartlarni o'qing va papkani tanlangFoydalanuvchi shartlari va maxfiylik siyosatini qabul qiling, o'rnatish papkasini tanlang — «Keyingi», «O'rnatish».
  3. GameClass bazasiga ulangOynada «Tekshiruv» va «GameClass bazasi» qadamlari — odatda faqat «Davom etish» ni bosasiz.
  4. Manajoy'ga ulangManaJoy Biznes ilovasida: Profil → Kompyuterlar holati → GameClass orqali ulash. 8 belgili kodni oynaga yozing.

Talablar

  • Windows 10 (1607) yoki Windows 11, 32 yoki 64-bit
  • GameClass Server o'rnatilgan kompyuter
  • Administrator huquqi va internet
  • ManaJoy Biznes ilovasi (klub egasi akkaunti)
